# Работа с sqlalchemy
Для подключения к БД через sqlalchemy, базово и минимально нужно создать 2 файла: config.py, database.py

## Config.py: 
Config.py - создается класс для конфига, у которого поля - это поля из файла .env. Класс наследуется от BaseSettings библиотеки pydantic_settings. Одно из полей класса - model_config = SettingConfigDict, оно отвечает за "магию" - присваивает поля из файла .env в поля класса, главное, что бы название полей былы одинаковы.

В классе создается метод для подключения к БД, который оборачивается в декоратор @property. В методе возвращается ссылка на подключение к БД. В конце файла создается экземпляр класса (не внутри самого класса).
### Пример Config.py:
```python
from pydantic_settings import BaseSettings, SettingsConfigDict

class Config(BaseSettings):
    DB_HOST:str
    DB_PORT:int
    DB_USER:str
    DB_PASS:str
    DB_NAME:str

    JWT_SECRETS:str
    JWT_EXPIRE_MINUTES:int
    JWT_ALGORITHM:str
    model_config = SettingsConfigDict(env_file= '.env')

    @property
    def DATABASE_URL(self):
        return f'postgresql+psycopg://{self.DB_USER}:{self.DB_PASS}@{self.DB_HOST}:{self.DB_PORT}/{self.DB_NAME}'
    
    @property
    def ASYNC_DATABASE_URL(self):
        return f'postgresql+asyncpg://{self.DB_USER}:{self.DB_PASS}@{self.DB_HOST}:{self.DB_PORT}/{self.DB_NAME}'
    
config = Config()
```

## Database.py:
Database.py - в этом файле мы объявляем две основные сущности:
- **engine** (движок) - объект, отвечающий за управление соединениями с базой данных. Он создает пул соединений, открывает подключения и используется Session для выполнения SQL-запросов.

- **session_maker** - фабрика сессий. Она используется для транзакций и представляет из себя преднастроенную сессию, с уже переданным движком и различными дополнительными настройками, которые, если бы не sessionmaker, нам бы постоянно приходилось бы писать при создании новой транзакции


### Пример Database.py:
```python

from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker
from sqlalchemy.orm import sessionmaker
from sqlalchemy import create_engine
from config import config

async_engine = create_async_engine(
    url=config.ASYNC_DATABASE_URL,
    echo=True
)
sync_engine = create_engine(
    url= config.DATABASE_URL,
    echo=True
)
async_session_maker = async_sessionmaker(bind=async_engine)
session_marker = sessionmaker(bind=sync_engine)

```
На данном этапе реализовано подключение к БД, теперь нужно создать модели (таблицы) для БД. Что бы это сделать создаем файл models.py

## Models.py
В этом файле под каждую отдельну модель создается свой класс. Классы таблиц наследуются от базового класса Base, который в свою очередь наследуется от класса DeclarativeBase из библиотеки sqlalchemy.orm
- **Mapped** - Это аннотация типа, которая сообщает SQLAlchemy, что атрибут является колонкой определенного типа
- **mapped_column()** - Определяет параметры колонки (будет ли PK, значения по дефолту, ограничения по длинне и тд.)
- **relationship()** - Инструмент для создания связей между таблицами и взаимодействия с ними, как с python объектами  
## Пример models.py 

```python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship
 

class Base(DeclarativeBase):
    pass

class UserModel(Base):

    __tablename__= 'users'

    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(String(100), unique=True, index=True)
    login: Mapped[str] = mapped_column(String(100), unique=True)
    album_id: Mapped[int] = mapped_column(ForeignKey("albums.id", ondelete="CASCADE"))
    password_hash: Mapped[str] = mapped_column(String)
    create_at: Mapped[time_now]
    albums: Mapped[list["AlbumModel"]] = relationship("AlbumModel",         back_populates="user", cascade="all, delete-orphan")
```

### Подробнее про relationship()
**relationship()** - это мощный инструмент, который превращает связи между таблицами базы данных в удобные, интуитивно понятные атрибуты Python-объектов.  
```python 
class User(Base):
    __tablename__ = "users"

    id = mapped_column(primary_key=True)
    name = mapped_column(String)
    
class Post(Base):
    __tablename__ = "posts"

    id = mapped_column(primary_key=True)

    title = mapped_column(String)

    user_id = mapped_column(
        ForeignKey("users.id")
    )
```

В колонке user_id должны храниться только id, которые существуют в таблице users. Больше ничего об этой колонке не знаем. Мы не можем:
- ❌ получать пользователя

- ❌ получать список постов

- ❌ делать объекты связанными 

Но, если мы используем relationship(), то он говорит SQLAlchemy:

```"Когда понадобится, свяжи объект User и объект Post"```

То есть ```user_id = 1``` превращается в ```post.user```, где ```post.user``` уже настоящий объект класса.

**Пример использования без relationship()**
```python 
class User(Base):
    __tablename__ = "users"

    id = mapped_column(primary_key=True)
    name = mapped_column(String)

class Post(Base):
    __tablename__ = "posts"

    id = mapped_column(primary_key=True)
    title = mapped_column(String)

    user_id = mapped_column(
        ForeignKey("users.id")
    )
```
Теперь, что бы получить пост нужно писать ```post = await session.get(Post, 1)``` и, если теперь мы захотим получить у этого поста пользователя, то мы не сможем написать ```post.user```, придется создавать новый запрос ```user = await session.get(User, post.user_id)```

```python
post = await session.get(Post, 1)
user = await session.get(User, post.user_id)
``` 

**Пример использования с relationship()**

```python
class User(Base):
    __tablename__ = "users"

    id = mapped_column(primary_key=True)

    name = mapped_column(String)

    posts = relationship(back_populates="user")

class Post(Base):
    __tablename__ = "posts"

    id = mapped_column(primary_key=True)

    title = mapped_column(String)

    user_id = mapped_column(
        ForeignKey("users.id")
    )

    user = relationship(back_populates="posts")
```

Теперь можно написать ```post = await session.get(Post, 1)``` и получить пользователя, к которому принадлежит этот пост ```print(post.user)```

### Параметры relationship(): ### 

- **back_populates**: Связывает две relationship() в обе стороны. При изменении одного атрибута автоматически обновляется другой, а также синхронизируются изменения в сессии
- **cascade**: Управляет каскадными операциями между объектами. Позволяет автоматически сохранять, удалять или обновлять связанные объекты вместе с родителем
- **lazy**: Определяет, когда и как будут загружаться связанные данные. Это один из самых важных параметров для производительности
- **secondary**: Используется только для связи Many To Many и указывает на промежуточную таблицу

## Примеры построение таблиц для различных связей 

### Один к одному (One-to-One)

```python
from sqlalchemy import ForeignKey, String
from sqlalchemy.orm import Mapped, mapped_column, relationship

class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String)

    passport: Mapped["Passport"] = relationship(
        back_populates="user",
        uselist=False
    )


class Passport(Base):
    __tablename__ = "passports"

    id: Mapped[int] = mapped_column(primary_key=True)
    number: Mapped[str] = mapped_column(String)

    user_id: Mapped[int] = mapped_column(
        ForeignKey("users.id"),
        unique=True
    )

    user: Mapped["User"] = relationship(
        back_populates="passport"
    )
```
**Важный момент -** именно эти две вещи делают связь один к одному:

- ```unique=True``` - Запрещает двум паспортам ссылаться на одного пользователя.

- ```uselist=False``` - говорит, что это не список

### Один ко многим (One-to-Many)

```python
class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str]

    posts: Mapped[list["Post"]] = relationship(
        back_populates="user"
    )


class Post(Base):
    __tablename__ = "posts"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str]

    user_id: Mapped[int] = mapped_column(
        ForeignKey("users.id")
    )

    user: Mapped["User"] = relationship(
        back_populates="posts"
    )
```
**Важный момент -** На стороне "один" тип — list[...], на стороне "многие" — один объект

### Многие ко многим (Many-to-Many)

Для реализации этой связи нужно делать промежуточную таблицу, которая будет хранить id основных объектов и на которую будет ссылаться relationship() 

```python
student_course = Table(
    "student_course",
    Base.metadata,

    Column(
        "student_id",
        ForeignKey("students.id"),
        primary_key=True
    ),

    Column(
        "course_id",
        ForeignKey("courses.id"),
        primary_key=True
    )
)

class Student(Base):
    __tablename__ = "students"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str]

    courses: Mapped[list["Course"]] = relationship(
        secondary=student_course,
        back_populates="students"
    )

class Course(Base):
    __tablename__ = "courses"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str]

    students: Mapped[list["Student"]] = relationship(
        secondary=student_course,
        back_populates="courses"
    )
```

**Важный момент -** Используется промежуточная таблица с двумя внешними ключами. Также, если промежуточная таблица будет хранить в себе **только** два внешних ключа и больше ничего, то делать ее следует через метод ```Table()```, если же в таблице будут дополнительные поля помимо внешних ключей, то стоит делать ее, как класс. 

### Пример методов для работы с БД
| Метод                      | Пример использования                                                                                         | Описание                                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `session.add()`            | `user = User(name="Kirill") session.add(user) await session.commit()`                            | Добавляет один объект в сессию. В БД попадет только после `commit()` или `flush()`.                                        |
| `session.add_all()`        | `users = [User(name="Kirill"), User(name="Alex")] session.add_all(users) await session.commit()\n` | Добавляет несколько объектов сразу.                                                                                        |
| `await session.commit()`   | `session.add(user) await session.commit()`                                                        | Подтверждает транзакцию и сохраняет изменения в БД.                                                                        |
| `await session.flush()`    | `session.add(user) await session.flush() print(user.id)`                                         | Отправляет изменения в БД без завершения транзакции. Часто используется для получения `id` новой записи до `commit()`.     |
| `await session.rollback()` | `try:   await session.commit()   except:    await session.rollback()`                          | Отменяет все изменения текущей транзакции.                                                                                 |
| `await session.refresh()`  | `await session.commit() await session.refresh(user)`                                              | Повторно загружает объект из БД, обновляя его поля.                                                                        |
| `await session.get()`      | `user = await session.get(User, 1)\n`                                                                | Получает объект по первичному ключу (`id`).                                                                                |
| `await session.execute()`  | `stmt = select(User) result = await session.execute(stmt)`                                        | Выполняет SQLAlchemy-запрос и возвращает объект `Result`.                                                                  |
| `await session.scalar()`   | `stmt = select(func.count(User.id)) count = await session.scalar(stmt)`                           | Возвращает первое значение первого столбца результата. Часто используется с агрегатными функциями (`count`, `max`, `min`). |
| `await session.scalars()`  | `stmt = select(User) users = await session.scalars(stmt) users = users.all()`                    | Возвращает `ScalarResult`, содержащий объекты модели вместо кортежей.                                                      |
| `await session.delete()`   | `user = await session.get(User, 1) await session.delete(user) await session.commit()`            | Помечает объект на удаление. После `commit()` запись удаляется из БД.                                                      |
| `await session.close()`    | `await session.close()`                                                                            | Закрывает сессию и освобождает соединение с БД. Обычно не вызывается вручную при использовании `async with`.               |

### Методы объекта Result

| Метод                  | Пример использования                                                                                                   | Описание                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `result.all()`         | `stmt = select(User) result = await session.execute(stmt) rows = result.all()`                             | Возвращает список всех строк результата в виде кортежей.                          |
| `result.first()`       | `stmt = select(User) result = await session.execute(stmt) user = result.first()`                           | Возвращает первую строку результата или `None`.                                   |
| `result.one()`         | `stmt = select(User).where(User.id == 1) result = await session.execute(stmt) user = result.one()`         | Возвращает одну строку. Если строк нет или их несколько — выбрасывает исключение. |
| `result.one_or_none()` | `stmt = select(User).where(User.id == 1) result = await session.execute(stmt) user = result.one_or_none()` | Возвращает одну строку или `None`. Если найдено несколько строк — ошибка.         |
| `result.scalar()`      | `stmt = select(User.name) result = await session.execute(stmt) name = result.scalar()`                     | Возвращает первое значение первого столбца результата.                            |
| `result.scalars()`     | `stmt = select(User) result = await session.execute(stmt) users = result.scalars().all()`                  | Извлекает объекты моделей из `Result`, убирая кортежи.                            |

### Методы объекта ScalarResult
| Метод                     | Пример использования                                                                                                 | Описание                                                                     |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `scalars().all()`         | `stmt = select(User)\nusers = await session.scalars(stmt) users = users.all()`                            | Возвращает список всех объектов модели.                                      |
| `scalars().first()`       | `stmt = select(User) users = await session.scalars(stmt) user = users.first()`                           | Возвращает первый объект или `None`.                                         |
| `scalars().one()`         | `stmt = select(User).where(User.id == 1) users = await session.scalars(stmt) user = users.one()`         | Возвращает один объект. Если найдено 0 или более 1 объекта — ошибка.         |
| `scalars().one_or_none()` | `stmt = select(User).where(User.id == 1) users = await session.scalars(stmt) user = users.one_or_none()` | Возвращает один объект или `None`. Если найдено несколько объектов — ошибка. |

### Самая часто используемая цепочка методов
| Код                                    | Что происходит                                        |
| -------------------------------------- | ----------------------------------------------------- |
| `stmt = select(User)`                  | Создаем SQLAlchemy-запрос.                            |
| `result = await session.execute(stmt)` | Отправляем запрос в БД и получаем `Result`.           |
| `users = result.scalars().all()`       | Извлекаем объекты `User` из результата в виде списка. |

Или в сокращенном варианте:
```python
users = (await session.execute(select(User))).scalars().all()
```
